# Lens Prompt Pilot

Google レンズの画面で、利用者が開始した後に定型操作を補助する Android アプリの試作です。参考画像（2026-10-22）では検索モードが選択され、画面下部中央に虫眼鏡アイコンの撮影／検索ボタンが表示されています。撮影後にレンズの検索入力欄へ定型プロンプトを入れることを目標にします。誤送信防止のため、検索の実行は利用者が確認して行う設計です。

## Android Studio で開く

1. このフォルダを Git リポジトリとして初期化し、GitHub 等へ push します。
2. Android Studio でリポジトリを clone するか、`File > Open` からこのフォルダを開きます。
3. Gradle Sync を実行し、Android SDK 35 をインストールします。
4. Android 端末を USB デバッグで接続し、Run でインストールします。

## 端末での使い方

1. アプリを開き、定型プロンプトを保存します。
2. 「アクセシビリティ設定を開く」から Lens Prompt Pilot を有効化します。
3. アプリで「入力待機を開始」を押すと Google アプリが開きます（Lens を直接開けない場合は Lens を手動で表示してください）。
4. レンズ画面下部中央の虫眼鏡アイコンを押して撮影／検索します。
5. 検索結果画面に「この画像について質問する」と表示された検索欄が出たら、この試作が欄を開き、フォーカスされた入力欄に定型プロンプトを入力します。
6. 入力内容を確認し、検索の実行は利用者が行います。

## 注意

参考画像の検索欄には「この画像について質問する」と表示されています。アプリはこの文言（または英語表示）を含むアクセシビリティ要素が Lens 画面に現れるまで待機し、その要素を開いてフォーカスされた編集欄だけに入力します。シャッターボタンは利用者が操作します。Google レンズは UI を変更することがあり、ラベルがアクセシビリティ要素として公開されない場合は対象アプリの実機調整が必要です。Google アプリの起動は Lens カメラを直接開く保証がないため、必要に応じて利用者が Lens を開いてください。すべての端末・Lens バージョンで動作する保証はありません。Android Studio で Gradle ビルドと実機確認を行ってください。
